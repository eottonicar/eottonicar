LINEA

Project-scoped AI assistance, persistent context and a decision history.

Explore the case

Problem: Long-running design projects accumulate decisions, revisions and context. A conventional chat history is not always enough to distinguish current decisions from superseded ones.

Approach: A project-oriented assistant with scoped conversations, persistent context and a decision history that makes changes explicit.

Scope: The project has explored SQLite persistence, LLM integration, decision records and end-to-end testing. No production scale, commercial performance or verified test count is claimed here.

Assistência contextualizada, memória persistente e histórico de decisões.

Domain-specific assistance, multimodal interaction and structured records.

Explore the case

Scope: The project has explored React, Vite, a PWA interface and AI API integration. It is not a clinically validated diagnostic tool and does not replace professional assessment.
